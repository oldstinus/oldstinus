# oldstinus workspace

This directory is a script workspace for multiple instrument- and workflow-specific projects.
It is not a single Python package. Each top-level folder is treated as a separate project area.

## Structure

- `ADCP_*`, `Multiparameter_*`, `Radar_*`, `TOPO-*`, `WATERINFO`, `Word-excel-ppt`: project areas
- `Druksensor_HR_OSSI`: reserved project folder, currently empty except for documentation
- `OLD`: archival material
- `docs`: repository conventions and maintenance notes
- `tests`: lightweight repository checks

## Working rules

- Keep executable source in project folders as `.py`, `.R`, or `.m` files.
- Keep generated output out of version control when possible.
- Do not commit virtual environments, logs, installers, or derived exports.
- Add a short `README.md` when a project folder is empty or serves as a placeholder.
