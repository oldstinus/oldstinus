ARX Model Analyse – Hydraulisch Systeem

1. Modeldefinitie

v_t = 0.030 |Δh| + 0.015 Δh - 7.878 d(Δh)/dt + 0.746 v_(t-1)

Dit model beschrijft de stroomsnelheid als functie van waterstandsverschil, dynamiek en systeemgeheugen.

2. Interpretatie van de termen

2.1 Niet-lineaire drukterm

0.030 |Δh|

  • Symmetrische bijdrage (richting-onafhankelijk)
  • Empirische benadering van energieverschil
  • Fysisch eerder √Δh verwacht

2.2 Lineaire component

0.015 Δh

  • Geeft richting van stroming
  • Corrigeert asymmetrie

2.3 Dynamische term

-7.878 d(Δh)/dt

  • Reageert op veranderingen in waterstand
  • Dempend effect (negatief teken)
  • Indicatie van opslag/inertie

2.4 Autoregressieve term

0.746 v_(t-1)

  • Systeemgeheugen
  • Traag systeem
  • Stabiel (coëfficiënt < 1)

3. Stationaire oplossing

v = (0.030 |Δh| + 0.015 Δh) / (1 - 0.746)

Versterkingsfactor ≈ 3.94

4. Regime-analyse

Regime Kenmerken Interpretatie
Normaal dΔh/dt ≈ 0 Gravitatie gestuurd
Transiënt snelle Δh veranderingen Dynamica dominant
Pomp model ≠ meting Externe forcing
Verzadiging v groeit niet meer met Δh Capaciteitslimiet

5. Diagnostiek

5.1 Pompdetectie

ε = v_measured - v_model

5.2 ADCP foutdetectie

  • Spike detectie (MAD / z-score)
  • Onrealistische snelheden

5.3 Hysterese

  • Verschil stijgende vs dalende Δh
  • Ingebouwd via |Δh| en dΔh/dt

6. Fysische interpretatie

Dit model beschrijft een hydraulisch systeem met:
  • Opslag (volume-effecten)
  • Inertie
  • Niet-lineaire stroming
  • Mogelijke pompinteractie

7. Modelverbeteringen

  • Gebruik √Δh in plaats van |Δh|
  • Voeg verzadiging toe
  • Expliciete pompterm
  • Hogere orde ARX model

8. Belangrijkste conclusie

De term d(Δh)/dt maakt het model dynamisch en geschikt voor:
  • Realtime analyse
  • Pompdetectie
  • Transiënt gedrag
